# 朋友圈回忆录 · Moments Memoir

把你发过的微信朋友圈，变成一本好看的回忆录网站。

在线教程：https://moments-memoir-guide.surge.sh

## 怎么用

1. **导出朋友圈**：用开源工具 [wxMoments](https://github.com/claudemt/wxMoments) 把朋友圈导到本地
2. **安装技能**：下载本仓库的 zip 包，发给豆包，说"帮我安装这个技能"
3. **生成回忆录**：跟豆包说"帮我做朋友圈回忆录，文件夹在 XXX"，回答几个选择题就行
4. **发布**：豆包会帮你部署到 surge.sh，得到一个链接发给朋友

## 效果示例

https://junran-memoir.surge.sh

## 目录结构

- `SKILL.md` — 技能主文件
- `references/` — 写作方法、风格模板、工作流
- `scripts/` — 导出数据分析脚本
- `assets/web-starter/` — 网站模板
