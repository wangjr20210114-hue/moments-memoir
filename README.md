# 朋友圈回忆录 · Moments Memoir

把你发过的微信朋友圈，变成一本好看的回忆录网站。

仓库地址：https://github.com/wangjr20210114-hue/moments-memoir

在线教程：https://moments-memoir-guide.surge.sh

## 怎么用（全程跟豆包说话）

1. **安装技能**：从 GitHub 下载 zip，发给豆包说"帮我安装这个技能"
2. **导出朋友圈**：跟豆包说"帮我导出朋友圈"，它会在桌面放个图标，你双击、扫码、等跑完
3. **生成回忆录**：把文件夹路径发给豆包，答几个选择题就行
4. **发布上线**：跟豆包说"帮我发布上线"，双击桌面部署图标，得到链接发给朋友

效果示例：https://junran-memoir.surge.sh
