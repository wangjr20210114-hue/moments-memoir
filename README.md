# 朋友圈回忆录 · Moments Memoir

把你发过的微信朋友圈，变成一本好看的回忆录网站。

## 使用方法

打开豆包，发这一句话：

```
帮我做朋友圈回忆录
https://github.com/wangjr20210114-hue/moments-memoir
```

剩下的豆包会自己搞定：下载工具、在桌面放图标、你双击扫码、回答几个选择题、生成网页、发布上线。

效果示例：https://junran-memoir.surge.sh
